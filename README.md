# 清華苑用ホーム画面ポータル (seikaen-home)

清華苑の業務アプリ、AIツール、マニュアル、動画マニュアルへ素早くアクセスできるスマートWebポータルです。
GitHub Pagesで24時間いつでもスマホ・PCの両方から高速にアクセスできます。

## 🌐 公開URL (GitHub Pages)
👉 **https://rokiwo.github.io/seikaen-home/**

---

## ✨ 主な特徴と機能
- **超爆速・快適な動作**: 従来のGAS版と異なり、起動待ち時間ゼロ（0.05秒）で瞬時に表示されます。
- **PWA対応**: iPhone・Androidの「ホーム画面に追加」で、アドレスバーのない完全なネイティブアプリ感覚で利用可能。
- **カテゴリー絞り込み**: 「すべて」「アプリ」「AI」「マニュアル」「動画マニュアル」「その他」のワンタップ切り替え。
- **スマート検索**: アプリ名やひらがな・カタカナのあいまいキーワードで即時絞り込み。
- **お気に入り（★）登録**: 端末ごとに★を付けて優先表示。
- **フォルダ管理**: 複数アプリをひとつのフォルダにまとめて整理。
- **ドラッグ＆ドロップ並び替え**: 編集モード（鉛筆ボタン）でアイコンがプルプル揺れ、直感的に並び替え可能（SortableJS）。
- **ファビコン自動補完**: アイコン画像がない場合でも、URLからサイトアイコンを自動取得。
- **オフラインキャッシュ**: Service Workerによるオフライン対応。

---

## 💻 別のPCで作業・編集したい場合
1. **ブラウザだけで編集**:
   - リポジトリページ（https://github.com/rokiwo/seikaen-home ）を開き、キーボードの **「 . 」（ピリオド）** を押すとWeb版VS Codeが起動し、その場で修正・保存できます。
2. **ローカル環境で作業**:
   - `git clone https://github.com/rokiwo/seikaen-home.git`
   - ファイルを更新後、`node deploy-github.mjs` を実行するだけでGitHub Pagesに自動反映されます。
